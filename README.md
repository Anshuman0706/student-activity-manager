# Student Activity Manager

A C/C++ student activity management project for organizing student
records and academic activities.

## Project Overview

The project contains C and C++ source files for managing student
information, examinations, and tasks. It also explores data
structures and object-oriented programming concepts.

## Project Structure

- `main.cpp` — Main application source
- `student.cpp` and `student.h` — Student-related implementation
  and declarations
- `exam.cpp` and `exam.h` — Examination-related implementation
  and declarations
- `task.c` and `task.h` — Task-related implementation
  and declarations
- `data/` — Project data files
- `Phase1/` — Files from the earlier project phase

## Technology

- C
- C++
- Data structures
- Object-oriented programming

## Development Notes

The C/C++ implementation is maintained separately from the
SmartCampus web application.

Before running the program, check the required source files and
compiler configuration. Keep generated object files and other
build outputs out of version control.
